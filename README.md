# AI-Driven Requirement Management System

## Overview

The AI-Driven Requirement Management System is a web-based application developed as my Final Year Project for my Bachelor of Computer Science (Hons.) in Software Engineering at Multimedia University (MMU).

The system aims to improve software requirement management by using AI-assisted analysis to help identify potential requirement defects, inconsistencies, and conflicts during software development.

## Objectives

- Improve the quality and clarity of software requirements.
- Reduce the time required for manual requirement analysis.
- Help identify ambiguous, vague, incomplete, or inconsistent requirements.
- Support better requirement management and traceability.

## Key Features

- **Requirement Management:** Create, organize, and manage software requirements.
- **AI-Assisted Analysis:** Analyze requirements using OpenAI integration.
- **Defect Detection:** Help identify potentially ambiguous, vague, incomplete, or inconsistent requirements.
- **Conflict Detection:** Identify potential conflicts between requirements.
- **Impact Analysis:** Support the assessment of changes to requirements.
- **Version Control and Traceability:** Support the tracking of requirement changes and relationships.

## Technologies Used

- **Backend:** PHP, Laravel
- **Database:** MySQL
- **AI Integration:** OpenAI API
- **Frontend:** Blade, HTML, CSS, JavaScript
- **Development Environment:** XAMPP, Composer

## Getting Started

### Prerequisites

- PHP
- Composer
- MySQL

### Installation

1. Clone this repository.
2. Install PHP dependencies using `composer install`.
3. Create a local environment file by copying `.env.example` to `.env`.
4. Configure the database connection in `.env`.
5. Add your OpenAI API key to the local environment configuration if required.
6. Generate the Laravel application key using `php artisan key:generate`.
7. Run the database migrations using `php artisan migrate`.
8. Start the development server using `php artisan serve`.

Follow the project's actual configuration and setup requirements if they differ from these instructions.
